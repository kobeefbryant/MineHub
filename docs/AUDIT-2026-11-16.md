# MineHub 审计记录 — 2026-11-16

## 1. 关于「30 张评测样本」

- 抽样：4.8 万 Ori 中随机 600 张 → SigLIP 分层 → 人工在缩略图拼版上核对 → 固定 30 图 + 5 视频
- 用途：比较 4 个模型的相对速度/显存/误判与 JSON 稳定性，决定流水线组合
- 局限：explicit 仅 5 张（召回刻度 20%）；分层基于模型预测存在选择偏差；人工粗标有主观误差；不能当作生产准确率

## 3. 缩略图纳入的折中策略

- 全部 40,682 张进入账本与 Stash
- 全部跑 SigLIP 粗筛（约 25 分钟）
- EnƟcing / Pornography 候选走 VLM A+B（预计 3–5 千张，约 1–1.5 小时）
- Normal / Anime / Hentai 直接按 SigLIP 落 daily / anime（`source='siglip-fast'`，带 `thumb_only` 标签）
- 因此这 4 万张中的聊天截图/表情包不会被细分为 screenshot/sticker；后续可清空其 `final_json` 后深度补标
